# 设定原则

本页记录“大明1914”的正典边界，帮助贡献者判断一个新设定是否适合加入。

## 基本前提

- 1644 年北京陷落，崇祯帝殉国。
- 南京朝廷没有立即崩溃，而是形成可持续的战时中央。
- 大明在 17 世纪中后期重新统一中国本部。
- 再统一后，大明正式定都南京，没有还都北京。
- 北京是北部战区和北疆外交核心，负责蒙古、俄罗斯、日本、女真和朝鲜方向。
- 近现代大明主权疆域包括今日中国本部、台湾、西伯利亚东部、外蒙古、藏南等地。
- 外蒙古和外兴安岭女真以联邦形式加入大明，没有外交军事权，但保留较高内政自治。
- 近代化不是一次改革完成，而是由财政、军制、海贸、教育、铁路、宪政等多轮改革累积而成。
- 到 1914 年，大明仍保留皇帝与国号，但实际政治运作接近君主立宪内阁制。
- 大明政党制度在夺回中原、南京定都后就开始制度化，制度发展长期领先世界。
- 大明通过文化、商业、科举和海军保护维持西太平洋藩属体系，而不是照搬西方殖民模式。
- 一战时期，大明的主要敌人是俄国和日本。
- 俄罗斯和日本长期暗中扶持外蒙古、外兴安岭女真和朝鲜方向的离心势力。
- 大明与外国多为小规模冲突，主要长期对外战争是新疆和西伯利亚方向的中俄百年战争。
- 英法在中南半岛与大明主要是外交、商业和殖民权益摩擦，没有爆发大规模军事战争。

## 写作口径

条目应尽量回答三个问题：

1. 这个事件或制度解决了什么问题？
2. 它制造了什么新问题？
3. 它影响了哪些后续条目？

## 禁止捷径

- 不使用现代技术提前数百年突然降临。
- 不让所有改革都毫无阻力。
- 不把外部世界写成静止背景。日本、俄国、英国、法国、荷兰、奥斯曼、美国等都应随时间变化。
- 不让一个人物独自解决结构性问题。

## 命名

项目名暂定为“大明1914”。若需要保留“大名1914”作为题名或双关，可在后续统一调整站点标题和仓库名。
