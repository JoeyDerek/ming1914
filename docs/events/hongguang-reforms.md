# 弘光新政

**弘光新政** 是再统一后的制度整理，始于 1659 年。它的目标不是现代化，而是让战时形成的财政和军政妥协变成可管理的制度。

## 财政改革

户部清查战时加派，将临时军费拆分为田赋附加、盐税、商税和海关收入。江南士绅接受部分常设税，但换取预算奏报和地方议税惯例。

这一步没有建立现代议会，却让“纳税者要求说明军费用途”成为政治常识。

## 军制改革

江北诸镇被改编为常备营与边防营。将领保留荣衔，但兵额、粮饷和军械由兵部核定。水师得到独立预算，用于长江、福建和广东海防。

## 官制改革

南京内阁在战后继续保留强势地位。皇帝仍掌握任命权，但重大军政事务必须经过内阁票拟、六部复核和廷议记录。

## 长期意义

弘光新政没有让大明成为近代国家，却留下三个长期传统：

- 财政公开给有限政治参与提供空间。
- 常备军让中央摆脱单纯依赖军镇。
- 内阁协商让皇权逐步制度化。
