# 总年表

## 1644-1659：南都抗战与再统一

- **1644**：李自成攻破北京，崇祯帝殉国。[南京朝廷](places/nanjing-court.md) 拥立福王 [朱由崧](people/zhu-yousong.md)，年号弘光。
- **1645**：清军南下受阻于淮扬防线，南京朝廷以江南田赋、盐税和海关临时加派维持军费。
- **1646**：[史可法](people/shi-kefa.md) 主持江北军政整编，江北四镇被纳入战时军饷体系。
- **1648**：南京朝廷承认部分地方团练与商税交换，换取江南士绅支持战费。
- **1651**：明军收复山东南部，漕运线恢复。
- **1653**：北京易手，明军重新进入旧都。朝廷决定不再还都北京，而是以南京为正式首都，北京改设北部战区和北疆外交行辕。
- **1657**：辽东、蒙古边镇重新划界，大明基本完成中国本部再统一。
- **1659**：[弘光新政](events/hongguang-reforms.md) 开始制度化战时财政和军制。

## 1660-1799：战后重建、早期政党与海贸国家

- **1662**：南京定都后，内阁议政形成固定党团。清议士绅、内廷近臣、海商集团和边防军政开始以稳定派系参与预算与官员任命，大明政党制度由此发端。
- **1668**：设海关总署，统一东南沿海税务。海商集团进入议政体系，成为后来工商会党和海权党的源流。
- **1683**：台湾纳入福建海防体系，成为海军与远洋贸易基地。
- **1712**：摊丁入亩提前制度化，人口税逐渐并入土地与商税；宗室岁禄开始收缩，形成后来的 [爵位与皇族](institutions/nobility-and-royal-family.md) 新制。
- **1736**：议政院前身“国议厅”常设化，清流、内廷、海商和边防派系可公开提交预算意见。大明制度成熟度长期领先同时代多数国家。
- **1764**：江南制造局前身成立，负责火器、船材和水师器械。
- **1796**：白莲教起事暴露地方财政与军队老化问题，巡防司成为近代 [警察机构](institutions/intelligence-and-police.md) 的前身。

## 1800-1884：近代化压力与中俄百年战争

- **1816**：俄罗斯越过贝加尔和黑龙江上游扩大商站，大明北部战区进入长期戒备。[中俄百年战争](events/sino-russian-hundred-years-war.md) 的边境冲突阶段开始。
- **1839**：广州禁烟危机引发大明与英国的海贸冲突，但双方都忌惮对方实力，冲突维持在外交、关税和商馆层面。
- **1842**：江宁商约签订，大明开放数处通商口岸并保留关税协商权。英法转而在中南半岛争取铁路、贷款和港口权益，牵制大明南方资源。
- **1856**：总理海防衙门成立，统筹外交、海军和通商事务。
- **1864**：新疆北路战役爆发，大明与俄罗斯在伊犁、塔城和天山北麓多次交战。朝鲜、越南和南洋商馆提供后勤、军费和转运。
- **1868**：京沪铁路试办，铁路、矿务、电报和 [教育与科举](culture/education-and-exams.md) 改革逐渐成为国家议题。
- **1875**：新军编练章程颁行，地方绿营逐步裁并。
- **1878**：北疆联邦章程颁行，外蒙古与外兴安岭女真确认加入大明联邦边疆，保留内政自治，但不得拥有外交军事权。
- **1879**：[雾港案](events/intelligence-operations.md) 暴露英法在暹罗和越南的殖民布局，东厂海外情报网成形。
- **1884**：[甲申宪改](events/1884-constitutional-reform.md) 通过，内阁责任制、[党派政治](politics/party-politics.md) 和预算审议成为正式制度。

## 1885-1914：停战划界、立宪大明与世界战争

- **1889**：西伯利亚东线战役后，大明与俄罗斯停战并启动划界谈判。双方承认边界现实，但没有真正和解。
- **1894**：[樱井文书](events/intelligence-operations.md) 显示日本军部企图朝鲜，大明扩大对朝军事顾问团。
- **1895**：中日海权危机后，大明扩大北洋、东洋、南洋三支舰队，并加强皇家渤海海军军官太学。
- **1901**：议政院扩权，早期党团转型为现代政党组织。
- **1908**：内阁总理大臣由议政院多数派推举，皇帝任命成为惯例。
- **1911**：辛亥政争后，朝廷确认内阁对议政院负责，避免共和革命。
- **1914**：欧洲战争爆发，俄国和日本趁势挑战大明 [藩属体系](diplomacy/tributary-order.md) 与 [联邦边疆](diplomacy/territory-and-federation.md)。大明把战争定义为东亚秩序保卫战，主要敌人为俄国和日本。
- **1917**：俄罗斯十月革命后，南京朝廷与商界对共产主义高度警惕，认为其会威胁皇室利益、商人阶级和藩属秩序。
