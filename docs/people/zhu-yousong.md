# 朱由崧

朱由崧，即弘光帝，是北京陷落后南京朝廷拥立的皇帝。

## 本设定形象

本设定不把朱由崧写成天才改革者。他的关键作用是接受一套限制皇权的战时妥协：让内阁、户部、兵部和江北军政体系获得足够权力，以换取朝廷存续。

## 政治处境

朱由崧的合法性来自明朝宗室身份，但他的实际权力受制于南京财政和江北军事。他若强行清算军镇或士绅，南京朝廷可能立即瓦解；他若完全放权，皇权又会失去号召力。

## 历史评价

后世对弘光帝评价分裂。保守史家称他“忍辱存社稷”，立宪派则认为他被迫开启了皇权制度化的道路。
