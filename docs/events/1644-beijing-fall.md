# 北京陷落

**北京陷落** 是“大明1914”的起点事件。1644 年，李自成率大顺军攻入北京，崇祯帝殉国，明朝北方中央体系崩溃。

## 史实背景

明末财政枯竭、辽东军费沉重、灾荒频发，中央对边军和地方的控制已经严重削弱。李自成入京后，北方官僚、军镇和士绅迅速重新站队。

## 本设定分歧

本设定的关键分歧不在北京，而在南京。南京六部、江南士绅、漕运官员和江北军镇没有因拥立问题彻底撕裂，而是在恐惧清军南下和大顺军扩张的压力下接受临时妥协：

- 拥立福王 [朱由崧](../people/zhu-yousong.md) 为帝。
- 南京保留中央名义，先不急于北伐。
- 江北军镇接受饷银和军令交换。
- 江南士绅接受临时加派，但换取战后税制清理承诺。

这个妥协很脆弱，却足够支撑 [南京抗战](nanjing-resistance.md) 的第一年。

## 后续影响

- 北京成为“失都”与北部战区重镇的政治象征。
- 南京从陪都变成战时首都，并在再统一后成为正式首都。
- 财政与军权的临时整合，成为 [弘光新政](hongguang-reforms.md) 的来源。
