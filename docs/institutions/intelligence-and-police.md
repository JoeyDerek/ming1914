# 东厂、西厂与警察机构

北京陷落后的大明没有废除厂卫传统，而是把它们改造成近代国家安全体系。到 1914 年，东厂负责海外情报，西厂负责国内情报，警察机构负责城市治安、刑事侦查和口岸秩序。

## 东厂

东厂名义上隶属内廷，实际经费由内阁秘密预算和皇家私库共同承担。它的核心任务是海外情报、藩属动向、联邦边疆外联线索、商馆保护、反间谍和远洋通信。

东厂在南洋、朝鲜、越南、日本、海参崴、伦敦和巴黎都设有“商馆书记”“海关译员”“学务参赞”等公开身份。它与海军关系密切，常利用商船、邮船和领事网络传递情报。

## 西厂

西厂负责国内政治安全、地方官员密报、铁路电报保卫、反叛乱侦察和科举舞弊调查。甲申宪改后，西厂被迫向内阁秘密委员会提交年度经费说明，但其档案仍由皇帝、总理大臣和内廷大臣共同保管。

## 警察机构

大明近代警察由巡防司演化而来，1902 年改组为内务部警政署。警政署管理城市警察、铁路警察、口岸巡警和刑事厅。

警察与西厂的分工并不总是清楚。普通刑案归警政署，政治案和涉外间谍案常被西厂接管，这也成为 [党派政治](../politics/party-politics.md) 中争议最大的议题之一。

## 监督机制

清流党要求废除厂名，改设国家情报局；内廷党坚持厂卫名称代表皇帝对国家安全的最后责任。最终妥协是保留东厂、西厂名号，但设立议政院秘密预算小组，少数议员可查阅经删节的年度报告。
