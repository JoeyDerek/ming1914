# 再统一战争

**再统一战争** 指南京朝廷从守住江南到重新控制中国本部的长期战争，大致持续于 1648 至 1657 年。

## 战争阶段

第一阶段是江淮反攻。南京朝廷恢复漕运，稳住山东南部和河南东部，切断清军南下补给。

第二阶段是华北争夺。明军以降将、团练和新编营混合推进，避免单纯依赖旧边军。北京于 1653 年被重新占领，但朝廷决定不再迁回，而是正式定都南京；北京改设北部战区和北疆外交行辕。

第三阶段是边镇重划。辽东和蒙古诸部没有被完全纳入直接统治，而是通过互市、封贡、边镇驻军和婚盟维持均势。

## 统一的含义

本设定中的“再统一”主要指中国本部行政、赋税和科举体系恢复，并不代表所有边疆都被同等程度直接治理。这个差异会影响后来大明面对俄国、日本和中亚局势的选择。

## 后续影响

再统一战争证明南京朝廷可以生存，但也迫使国家承认几个现实：

- 军队必须由中央财政稳定供养。
- 税制不能只依靠传统田赋。
- 边疆政策必须兼顾军事和贸易。
- 皇帝无法绕过内阁、户部和军方直接治理整个帝国。
- 南京是新国家的政治财政核心，北京是北部战区的军事外交核心。
