# 南京朝廷

**南京朝廷** 是北京陷落后大明延续的政治中心。它原本只是陪都官僚体系，却在 1644 年后承担中央政府职能，并在北京收复后成为大明正式首都。

## 组成

南京朝廷由南京六部、留都勋臣、江南士绅、漕运官员、盐政系统和江北军镇共同支撑。它的力量不来自完美团结，而来自各方都无法单独承受清军南下和秩序崩溃的代价。

## 政治特点

- 财政依赖江南田赋、盐税和商税。
- 军事依赖江北防线与长江水师。
- 合法性依赖拥立 [朱由崧](../people/zhu-yousong.md)、恢复中国本部秩序，以及把南京从陪都转为新都的制度安排。
- 决策依赖内阁、六部、军镇和士绅之间的妥协。

## 长期影响

南京朝廷让大明从北方边防帝国转向更重视江南财政、海贸和水师的国家。北京后来收复后，大明没有还都，而是正式定都南京；北京改为 [北部战区核心](beijing.md)。南京由此成为皇帝、内阁、议政院、中央财政和海贸政策的所在地，并成为清流党、工商会党和海权党最重要的政治基地。
