# 一次世界大战

1914 年欧洲战争爆发时，大明已经是东亚主要国家之一。它拥有工业化沿海省份、成体系的海军、庞大陆军、铁路干线、近代大学和有限选举产生的议政院。

## 战略处境

大明的核心利益不在欧洲本土，而在东亚海权、朝鲜、辽东、外蒙古、外兴安岭、南洋侨商、印度洋航线，以及 [藩属体系](../diplomacy/tributary-order.md) 与 [联邦边疆](../diplomacy/territory-and-federation.md) 的稳定。欧洲战争爆发时，大明仍背负 [中俄百年战争](sino-russian-hundred-years-war.md) 的财政和边防后遗症。

战争爆发后，俄国试图拉拢外蒙古王公、北元旧贵族和外兴安岭女真贝勒，从陆路牵制大明；日本则以朝鲜政争、侨民保护和支援女真自治为借口准备出兵。大明因此把一战东亚战场的主要敌人确定为俄国和日本。

## 主要敌国

- **俄国**：目标是切开大明与朝鲜、辽东、外蒙古和外兴安岭的联系，并利用北元、女真旧贵族制造联邦边疆危机。
- **日本**：目标是夺取朝鲜影响力，挑战黄海和日本海制海权，并通过外兴安岭女真自治派撬动大明北疆。

英法在越南、暹罗和南洋仍有殖民企图，但 1914 年不是大明的主要敌人。德国则更多是欧洲战争变量，而非大明东亚战略的核心。

英法与大明在中南半岛主要是外交和商业摩擦，没有爆发大规模军事战争。双方都清楚，一旦开战，南洋航线、印度洋贸易和欧洲殖民体系都会付出巨大代价。

## 国内政治

议政院多数派支持对俄日采取强硬路线，理由是朝鲜和西太平洋秩序一旦失守，大明的 [文化与商业扩张](../diplomacy/expansion.md) 将失去根基。保守派担心战争会扩大新军权力，商界则更关心航运保险、关税和海外市场。

[党派政治](../politics/party-politics.md) 在战争中明显分裂。边防党主张先发制俄，海权党主张封锁日本，清流党要求内阁先取得议政院授权，内廷党则强调皇帝作为国家元首必须亲自批准宣战。

## 战争目标

- 保全朝鲜和辽东安全。
- 阻止日本吞并或控制朝鲜。
- 切断俄国、日本对外蒙古王公、北元旧贵族和外兴安岭女真自治派的军械、贷款与顾问。
- 维护西太平洋航线和南洋藩属国安全。
- 在战后会议中确认大明对东亚秩序的主导权。

## 待定问题

- 大明是否在 1914 年立即对俄日宣战，还是先以武装护藩名义动员？
- 日本是否先攻朝鲜，还是先袭击琉球和东洋舰队？
- 大明在战后会议中提出何种国际主张？
