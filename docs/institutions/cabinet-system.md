# 内阁制

**内阁制** 是大明近代政治的核心制度。它不是从西方一次性移植而来，而是由明代内阁、战时廷议、财政公开和 19 世纪议政制度逐步演化形成。内阁首长的演变见 [内阁首辅与总理大臣](chief-councillors.md)。

## 权力结构

- 皇帝是国家元首，保留任命、册封、外交批准和军队统帅名义。
- 内阁总理大臣主持政府，通常由议政院多数派推举。
- 各部尚书兼任内阁大臣，对政策和预算负责。
- 议政院审议预算、税法、条约和战时授权。

## 运作惯例

到 1908 年后，皇帝通常任命议政院多数派领袖为内阁总理大臣。若内阁预算被否决，通常需要改组内阁或请求皇帝解散议政院重新选举。

内阁必须面对 [党派政治](../politics/party-politics.md) 的约束。清流党、内廷党、工商会党、海权党和边防党都能通过预算、质询和不信任动议影响阁政。

## 历史来源

内阁制的远因可追溯到 [南京抗战](../events/nanjing-resistance.md) 中形成的议饷传统，以及 [弘光新政](../events/hongguang-reforms.md) 对财政和军令的制度化。

## 1914 年状态

1914 年的一战决策不是皇帝个人决定。内阁、议政院、军部、海军部、[东厂与西厂](intelligence-and-police.md) 和商界都参与博弈，这使大明对外政策更稳定，也更迟缓。
