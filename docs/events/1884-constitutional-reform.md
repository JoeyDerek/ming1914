# 甲申宪改

**甲申宪改** 是 1884 年通过的一组宪制改革，也是大明从传统君主制转向近代内阁制的关键节点。

## 背景

19 世纪的大明面临海贸冲突、铁路债务、军费膨胀和地方议政扩张。旧有廷议和内阁票拟已经不足以处理预算、条约和工业政策。

## 主要内容

- 设立议政院，负责审议预算、税法和重大条约。
- 内阁总理大臣主持政务会议，统合六部和新设部院。
- 皇帝保留任命、外交批准和军队统帅名义。
- 法律、预算和战时特别授权必须留下公开记录。

## 妥协

甲申宪改不是民主革命，而是朝廷、士绅、商人、新军和地方督抚之间的妥协。它限制皇权，也限制街头政治；它提高行政效率，也让党争进入中央。
