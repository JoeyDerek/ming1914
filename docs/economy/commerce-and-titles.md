# 商业与捐爵

大明海贸发达，商人却长期受儒家名分影响，社会地位低于文官、军功贵族和科举士人。因此，许多大商人通过捐输、军费认购、铁路债券和皇家基金换取爵位。

## 商人地位

商人掌握航运、银号、矿务、铁路、保险和南洋商馆，却常被清流士人批评为逐利。工商会党兴起后，商人开始要求统一商法、破产法、公司章程和议政院席位。

## 捐爵制度

捐爵以子爵、男爵和勋爵最常见，通常不能世袭太久，也不自动获得官职。大商人捐爵后可进入宫廷宴会、商政咨询会和部分慈善董事会，子弟入学也更容易获得荐举。

## 争议

清流党认为捐爵败坏名器，工商会党则认为商税和战争公债支撑国家，商人应获得相应荣誉。内廷党支持捐爵，因为皇家私库和海军基金都依赖富商捐输。

## 与海权的关系

大明海军强盛离不开商人。远洋邮船、煤站、保险公司和船厂多由商界投资，战时则可被国家征用。商人虽然名分不高，却是 [文化与商业扩张](../diplomacy/expansion.md) 的核心力量。
