# 南京抗战

**南京抗战** 指 1644 至 1648 年间，南京朝廷在江淮一线抵抗清军、大顺残部和地方割据势力的战时阶段。

## 战略目标

南京朝廷的首要目标不是立刻收复北京，而是守住江南财赋区、淮扬门户和长江水道。只要南京不失，朝廷就有粮、有银、有工匠，也有继续谈判和整编军队的时间。

## 淮扬防线

[史可法](../people/shi-kefa.md) 被授予江北军政大权。他的权力来自三个妥协：

- 南京承认江北诸镇既有兵额。
- 江北诸镇接受户部和兵部联合核饷。
- 盐商、漕帮和地方团练被纳入后勤体系。

淮扬防线没有彻底击败清军，但拖慢了南下速度。清军需要同时处理北京秩序、山海关后勤、北方降将和江淮水网，无法像真实历史中那样迅速夺取南京。

## 政治代价

南京抗战让大明存活，却也留下严重后遗症。军镇得到合法地位，士绅得到议税权，户部财政开始依赖商税与海关。这些临时让步后来成为 [内阁制](../institutions/cabinet-system.md) 的远因。
